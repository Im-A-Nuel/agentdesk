# Design read

## Product and user

AgentDesk is an onchain permission desk for hackathon judges and crypto users who need to inspect evidence quickly. The interface should feel like a legible transaction ledger, not a speculative trading dashboard.

## Visual language

- Warm brass signals signed authority and ledger marks without using the common blue-purple crypto gradient.
- Near-black ink and warm neutral panels keep registry data and transaction hashes dominant.
- Sora is limited to headings, Manrope handles prose, and JetBrains Mono marks addresses, values, IDs, and hashes.
- Controls use moderate rectangular radii. Pills remain appropriate only for compact status badges.
- Decorative glow, looping ticker motion, and fabricated dashboard previews are intentionally absent.

## Dials

- Energy: 2/5
- Visual density: 3/5
- Rhythm variation: 2/5
- Motion intensity: 1/5

Motion communicates entry, hover, loading, or state change and respects `prefers-reduced-motion`.
